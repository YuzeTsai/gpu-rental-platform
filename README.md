# 算力顯卡租借平台

用 Google 試算表 + Google Apps Script 做的 GPU 租借網頁應用程式（「與 AI 協作」課程 APP 設計作業）。

經濟四　B11302212　蔡佑澤

## 功能

- 方案介紹：13 款顯卡的規格、用途、時租與即時可用台數，可依等級篩選
- 立即租借：選顯卡 → 選時段（逐小時檢查是否租滿）→ 填資料 → 確認訂單，即時計價
- 學生 8 折、優惠碼（從試算表驗證）、逾時以 1.5 倍時租計費
- 預約、取消、結束租用時自動寄信
- 我的訂單：以 Email 或訂單編號查詢、取消預約、結束租用
- 營運報表：近 30 天營收、使用率、每日營收、熱門顯卡、客群與優惠碼統計

## 部署

1. 建立 Google 試算表，分頁：`顯卡方案`、`租借訂單`、`優惠碼`（欄位見報告「資料設計」），時區設為 Asia/Taipei。
2. 擴充功能 → Apps Script，貼上 `Code.gs`，新增 HTML 檔 `Index` 貼上 `Index.html`。
3. 執行一次 `seedDemo` 產生範例訂單（同時完成授權）。
4. 部署 → 新增部署作業 → 網頁應用程式（執行身分：我）。
